# Post-Development Roadmap: Tonight's Kitchen (今晚吃什么)

This guide outlines the exact steps required to transition your project from initial AI-scaffolded UI code to a production-ready, database-backed, open-source Progressive Web App (PWA).

---

## Step 1: Save Context & Set Up Project Rules (`AGENTS.md`)

Before closing your active OpenCode process, document the app state so future sessions read it automatically.

1. **Prompt OpenCode:**
   > "Generate an `AGENTS.md` file in the root directory. Document the tech stack (React PWA + Supabase), app architecture, user roles (Diner vs Chef), design rules, and verification commands (`npm run dev`, `npm run build`)."
2. OpenCode will generate and save the file. Any future `opencode` session opened in this directory will automatically load `AGENTS.md`.

---

## Step 2: Set Up the Free Backend (Supabase Integration)

Replace local mock data with a cloud database so real-time orders update between phones.

1. Create a free account at [Supabase.com](https://supabase.com) and set up a new project.
2. Open the **SQL Editor** in Supabase and run the following setup script:

```sql
-- Dishes Table
CREATE TABLE dishes (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL, -- 主食, 蔬菜, 肉类, 汤品, 小吃
  calories INT,
  recipe_url TEXT,
  image_url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Orders Table
CREATE TABLE orders (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  dish_ids JSONB NOT NULL,
  status TEXT DEFAULT 'pending', -- pending, preparing, served
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Wishlist Table
CREATE TABLE wishlist (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  dish_name TEXT NOT NULL,
  category TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

3. Go to **Storage** in Supabase, create a bucket named `dish-images`, and set its bucket policy to **Public**.
4. Retrieve your `API URL` and `anon key` from Supabase Settings $\rightarrow$ API.
5. Create a local environment file named `.env.local` in your root folder:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

6. **Prompt OpenCode:**
   > "Install `@supabase/supabase-js`. Connect our dish components, order flow, and image uploads to Supabase using the environment variables defined in `.env.local`."

## Step 3: Run Automated End-to-End Tests (Playwright)

Verify the ordering and role flows function properly without breaking component states.

1. **Prompt OpenCode:**
   > "Install `@playwright/test`. Write an automated browser test in `e2e/ordering.spec.js` that opens the app as a Diner, adds a dish to tonight's order, submits it, and verifies that the item appears on the Chef dashboard."
2. **Execute the test suite in your terminal:**
   ```bash
   npx playwright test
   ```

---

## Step 4: Security & Git Sanity Check

Prevent private keys or node files from leaking into your public repository.

1. Ensure a `.gitignore` file exists in the root folder with the following entries:
   ```text
   node_modules/
   .env
   .env.local
   .env.production
   dist/
   build/
   .DS_Store
   ```
2. Scan component code to confirm no secret tokens, API keys, or personal URLs are hardcoded into source files.

---

## Step 5: Deploy the App (Vercel)

1. Push your local codebase to a new public repository on GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: complete MVP for Tonight's Kitchen PWA"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/tonights-kitchen.git
   git push -u origin main
   ```
2. Sign in to [Vercel.com](https://vercel.com) using your GitHub account.
3. Click **Add New Project** and select `tonights-kitchen`.
4. In the **Environment Variables** section, enter `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
5. Click **Deploy**. Vercel will build and output your production HTTPS URL (e.g., `https://tonights-kitchen.vercel.app`).

---

## Step 6: Mobile PWA Installation

Install the deployed app directly to mobile home screens without an app store:

* **iOS (Safari):** Open the Vercel URL $\rightarrow$ Tap **Share** $\rightarrow$ Tap **"Add to Home Screen"** (添加到主屏幕).
* **Android (Chrome):** Open the Vercel URL $\rightarrow$ Tap the 3 dots menu $\rightarrow$ Tap **"Install App"** / **"Add to Home Screen"**.
